# philippguldimann.ch

Source for my personal site — built with Jekyll, deployed via GitHub Pages.

## Structure

- `index.md` — landing page: positioning, experience, research, education, skills
- `thesis.md` — case study on my MSc thesis (Whisper adaptation to non-normative child speech)
- `writing.md` — index for the *Harness engineering* series
- `_posts/` — published articles · `_drafts/` — work in progress
- `_layouts/`, `_includes/`, `assets/` — custom theme (no remote theme)

## Local preview

```bash
bundle install
bundle exec jekyll serve
```
